# Лабораторная работа №4 "Мобильное приложение "Город""

Приложение представляет собой интерактивный гид по городу, предлагающий три основные категории:  
* Культурные места;
* Природные достопримечательности;
* Исторические достопримечательности. 

Для каждой категории доступны рекомендации с подробным описанием, которое отображается при нажатии на элемент.
